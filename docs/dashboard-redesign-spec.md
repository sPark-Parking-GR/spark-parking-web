Keep login-redesign tokens/keyframes (--ease,--spring,--out, brand gradient, glow); reuse existing buttons/focus rings/LanguageSwitch.

Header of sidebar: brand mark + italic "sPark" wordmark + role pill ("Admin"/"Operator"); close button in overlay modes.
